```
  t= 609s logged_in= 60 free=  2 ringing=  2 waiting=0 FALLBACK_PROGRESSIVE  approved= 0 cancelled= 0 | R3 fallback: agent drop: 40 of 100 agents left in 10s
  t= 610s logged_in= 60 free=  1 ringing=  1 waiting=0 FALLBACK_PROGRESSIVE  approved= 2 cancelled= 0 | R3 fallback: agent drop: 40 of 100 agents left in 10s
  abandoned in the whole run: 2   invariant violations: 0
```
Reaction time: one pacing tick (1 s). The drop window sees agents going OFFLINE, the controller switches to FALLBACK_PROGRESSIVE (60 s cool-down) and cancels the newest ringing calls that the remaining agents could not absorb - before those borrowers answer. Calls that have been ringing for a long time are kept: the age-aware model knows they are unlikely to be answered.
